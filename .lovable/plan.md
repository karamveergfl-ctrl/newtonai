# SmartBoard handoff pack for Claude

Goal: one self-contained bundle you can paste/upload into Claude — every file that makes SmartBoard work, plus a flowchart of the runtime flows.

## What gets produced

1. `/mnt/documents/smartboard-handoff.md` — a single markdown document containing:
   - **System overview**: the SmartBoard tier, how it is isolated from the normal student/teacher app.
   - **Data model**: `sb_institutions`, `sb_boards`, `sb_board_usage`, `sb_institution_admins` with columns, RLS policies and the `sb_*` SECURITY DEFINER functions (`sb_create_board`, `sb_reissue_board_code`, `sb_link_institution_admin`, `sb_list_institution_admins`, `sb_generate_activation_code`, `sb_admin_institution`, `is_sb_admin`), dumped from the live database.
   - **Full source code**, each file in a fenced block with its path:
     - Edge functions: `smartboard-activate`, `smartboard-signin`, `smartboard-session`, `smartboard-video-search`, `smartboard-log-play`, `smartboard-extract-document`, plus shared `_shared/smartboard-auth.ts` and `_shared/office-extract.ts`.
     - Client lib: `src/lib/smartboardSession.ts`, `src/lib/smartboardCredentialPdf.ts`.
     - Pages: `src/pages/smartboard/*`, `src/pages/smartboard-admin/*`, `src/pages/admin/SmartBoards.tsx`.
     - Components: all 17 files in `src/components/smartboard/`, `src/components/smartboard-admin/AddBoardModal.tsx`, `src/components/onboarding/SmartBoardOnboarding.tsx`, `src/components/routes/SmartBoardDeviceRedirect.tsx`.
     - Routing: the SmartBoard-relevant excerpt of `src/App.tsx`.
   - **Known issues / open questions** section left for you to fill with the exact problem Claude should solve.

2. `/mnt/documents/smartboard-flow.mmd` — Mermaid flowchart covering:
   - Activation-code path: `/smartboard/activate` → `smartboard-activate` → device token hashed into `sb_boards` → localStorage kiosk session.
   - School-account path: sign in → onboarding SmartBoard tile → `smartboard-signin` (list boards, then mint token).
   - Kiosk persistence: app root → `SmartBoardDeviceRedirect` → `/smartboard/classroom` → `smartboard-session` verify.
   - Teach mode: topic search → `smartboard-video-search` (3-key YouTube fallback + `youtube_search_cache`) → play → `smartboard-log-play` → `sb_board_usage`.
   - Document mode: docx/pptx upload → `smartboard-extract-document` (JSZip) → teaching view.
   - Admin paths: platform `/admin/smartboards` and school `/smartboard-admin/dashboard` → `sb_create_board` / `sb_reissue_board_code` → credential PDF.

## Notes

- The bundle is generated by a script that reads the files directly, so nothing is paraphrased or abbreviated — Claude gets the real code.
- Expect roughly 4,000+ lines of source; the document is split with clear headings so it can be chunked if it exceeds Claude's paste limit.
- "Other functions" is scoped here to everything SmartBoard touches. If you also want unrelated subsystems (Newton chat, live sessions, study tools) in the same pack, say so and I will add those sections.
